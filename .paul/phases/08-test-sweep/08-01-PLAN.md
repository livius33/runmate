<objective>
## Goal
A kettlebell marker switched on in the week editor stays on. Cause: the PUT schema of /api/running/plan-overrides
lists only date, type, km, title, notes, pace and key; zod drops everything else. The saved edit therefore loses
`strength` (kettlebell), `was` (the pace session kept behind a Zone 2 switch), `anchor`, `test` and `paused`, and the
refetch shows the plan without them.

## Purpose
Manual edits are the runner's word. Losing part of one silently is the worst kind of plan bug.
</objective>

## AC-1: Kettlebell toggle survives the save
```gherkin
Given a run day without a kettlebell marker
When I switch "Kettlebell" on in the day's details and the save round-trips through the API schema

```

## AC-2: Zone 2 ↔ pace keeps the pace session
```gherkin
Given a tempo day switched to Zone 2
When the edit is saved and loaded
Then `was` still holds the tempo session and "zurück zu Tempo" restores it
```

## AC-3: The schema still rejects junk
```gherkin

Then the API answers 400
```
